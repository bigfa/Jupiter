# Jupiter App Icon Redesign Design

**Goal:** Redesign the iOS app icon in the same warm, minimal, rounded style as the provided references while shifting the subject to a stacked Polaroid album concept.

## Visual Direction

- Base: soft cream rounded-square app icon background.
- Focal composition: a muted warm-red circular disc centered behind the symbol.
- Symbol: two stacked Polaroid frames, with the rear frame offset slightly up-left and the front frame centered.
- Interior illustration: extremely simple landscape/photo hint inside the front frame, using thin warm-brown lines and one small Jupiter-inspired dot/star accent.
- Finish: subtle soft shadow, no harsh contrast, no photorealism, no heavy gradients.

## Palette

- Cream background
- Warm red accent circle
- Cocoa-brown linework
- Pale gold highlight accents

## Success Criteria

- Reads clearly as an album/photo app at small sizes.
- Feels stylistically aligned with the supplied references.
- Can be exported as a single 1024x1024 PNG for the current Xcode `AppIcon` asset.
